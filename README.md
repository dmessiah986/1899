# The South African War, 1899–1902: a virtual tour

A static website for CAPS History Grade 10, Term 4, Topic 6 (The South African War and Union). No build step or installs are needed.

## Put it on GitHub Pages
1. Sign in at github.com and choose **New repository**. Name it (for example `sa-war-virtual-tour`), set it to Public, and create it.
2. Choose **Add file > Upload files**, drag in `index.html` (and an `assets` folder for your images), then **Commit changes**.
3. Open **Settings > Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. After a minute your site appears at `https://YOUR-USERNAME.github.io/sa-war-virtual-tour/`. Share that link with learners.

## Customise
- Open `index.html` and edit the `A` array: each area has text, a source, questions with marks and cognitive level, and links.
- Set `GOOGLE_EARTH_URL` near the top of the script to show a Google Earth button.
- Save images in `assets/` and add `img:"assets/yourfile.jpg"` to an area’s `src`. Credit the creator, title, date and collection in the caption.
